* Understand what this course is about

- This is what the *course catalog* says:
  #+begin_quote
  "This course is a continuation of *Computer Science II* and provides a
  deeper look into *object oriented programming*, generic *types*, *lambda*
  functions, *stream( processing, and *concurrent* processing. It also
  presents several basic *data structures*: stacks, queues, lists,
  trees, and graphs. *Algorithms* for sorting, searching, and memory
  management are also introduced."
  #+end_quote

- *Prerequisite*: COSC 1220 Computer Science II
  #+begin_quote
  "A broadening of foundations for computer science with advanced
  concepts in software engineering and program development. Topics
  include an introduction to *data structures*, *analysis of algorithms*,
  and *object-oriented design*."
  #+end_quote

- What you should already know (concepts/theory):
  #+begin_quote
  - Program structure and the compile/run model (~javac/java~)
  - Primitive types, expressions, casting
  - Conditionals and loops (~if~, ~while~, ~for~, nesting)
  - Arrays
  - Standard I/O (~StdIn/StdOut/StdDraw~)
  - Simulation / Monte Carlo style programs
  - Markov chains / transition matrices
  - Function definition, parameters, return values, ~static~ methods
  - Modular decomposition (libraries vs. clients)
  - Recursion (base case, recursive case, call stack)
  - Encapsulation (fields + methods, constructors)
  - API design (exposed vs. hidden state)
  - Instance methods vs. ~static~ methods
  - Reference types vs. primitives
  - Aliasing and mutability
  - Defensive copies
  - Using existing data types
  - Creating custom data types
  - Designing (well-formed) data types
  - Composing multiple types into a larger program
  #+end_quote

- What you should already be able to code:
  #+begin_quote
  Design, implement and test a simply abstract data type that you can
  use to model a real time object - for example a stopwatch to compare
  running times of performance-critical methods.
  #+end_quote

- What you will add in this class:
  #+begin_quote
  You will learn to "pay attention to the cost" of your code. You will
  build linked structures that can be arbitrarily complex. With
  these, and with arrays, you can build *data structures* 
  #+end_quote

- This is what the course is really about:
  #+begin_quote
  1. Learn how to tell a machine what to do safely, clearly, and in a
     way other programmers can trust and build on.
  2. Learn how to write programs that work, scale and perform.
  3. Learn to use the computer as a tool for bigger and messier jobs.
  #+end_quote
